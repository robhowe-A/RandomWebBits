TRY: Surfing PowerShell Drives

Windows uses PowerShell as an API to interact with the OS in many ways. The scripting language is common for administration automation and accessing CSOM and SSOM methods.

Certificates' drive can be accessed in PowerShell's cert:\ location. Instead of browsing a drive letter, the shell reads information from the isolated OS partitions.

Multiple PowerShell drives are available to review:

  • cert:\
  • hklm:\
  • env:\

Reading the contents of the drive is similar to changing directories Ex: cd c:\ in command prompt, using drive Ex: cd env:\

Web administrators are familiar with maintenance needed for HTTPS delivery. Often, certificates will expire on a web or application server. The (above) script would be used to find certificates expiring within a 1 year's range.
