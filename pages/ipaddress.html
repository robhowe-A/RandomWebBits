TRY: Looking up your IP Address

Data runs the internet, and data always originates from somewhere. Two IP addresses are important.

1.) Local IP: the device address assigned by a router or DHCP server on the network. You can find the local IP in many locations:

2.) Public IP: the network's IP address assigned by a service provdier (ISP). The browser requires a connection into your network, so it's a good place to find your public visible IP address.

Options:

  1. Search Engine - The browser can return the public IP
  2. iP ChiCKEN - Websites can find and show the public IP
  3. Location Lookup - This website has location information along with the public IP

Do NOT share your public ip.
It belongs to you and is secure not to share it with anyone.
