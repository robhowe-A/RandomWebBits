TRY: Finding markup differences

JavaScript requires HTML to load before the JavaScript code. Developers often choose to load their websites with small amounts of HTML, allowing JavaScript to fill in after. This results in different source code than what is applied during browsing.

Blazor, Angular, and React web applications are based on this concept. Each app begins its page render with small HTML source code, then fills in the ramining markup as it's needed.

  • CTRL + U to open source code.
  • CTRL + SHIFT + I to open elements inspection
