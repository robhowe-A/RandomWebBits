TRY: Installing Wappalyzer

The browser extension is available in major browser brands. If you are curious what technologies run a website, the extension will show a breakdown of the site page's technology in use.

  • HSTS, or HTTP Strict Transport Security, security implementation
  • List implementations:
    • JavaScript frameworks
    • JavaScript libraries
    • PaaS
    • Analytics

Wappalyzer browser extension analyzes simple and complex web applications. RWB [02-14-2023] shows it is currently hosted on Netlify.

The app extension uses JavaScript to send and receive messages from the browser about the technologies used.

The extension links to much more information, allows API usage. The app's site is here: Wappalyzer Apps
