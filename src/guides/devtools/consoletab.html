GUIDE: Dev Tools --> Console Tab

Open the dev tools tab with CTRL + SHIFT + J and navigate to the console tab. In firefox, be sure to use CTRL + SHIFT + I

Key F12 opens the dev tools directly to the console.

There may be a flurry of information and/or errors. Each error highlights a problem and usually comes with a description of what type of error has been encountered. The output also includes a reference to where in the source code the error occurred.

Console information can be useful to developers, security specialists, and designers. Searching and reviewing for errors is frequent throughout a site's creation.

Test: Click on the message's link to be taken to the source code specific of the message.
