GUIDE: Dev Tools --> Elements Tab

Open the dev tools tab with CTRL + SHIFT + J and navigate to the elements tab. In firefox, be sure to use CTRL + SHIFT + I

All of the DOM elements are viewable in a tree structure. See <DOM> for more details. Elements' CSS properties are visible in the right part of the panel's display.

Below, the elements tab surfaces (varying) problems and uses the console to display errors and warnings, as pictured here:

If the page is without console errors, the button does not appear.

Additionally: A part of development is making sure the markup adheres to the browser's specifications and writing standards. Clicking the blue comment bubble opens a list of recommendations for improvement. This option is not available in firefox browser.

Note:"Improvements" is shown in Chromium's developer toolset, so use Edge or Chrome to see the feature.

Examples are using Edge browser. Chrome and Firefox use similar keyboard shortcuts and application layout information.
