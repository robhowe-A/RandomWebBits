GUIDE: Dev Tools --> Lighthouse Tab

Open the dev tools tab with CTRL + SHIFT + J and navigate to the Lighthouse tab. A Lighthouse tab does not exist in Firefox. Instead, Mozilla has a browser extension available from their ADD-ONS subdomain.

Results are similar of either the developer tools or extension tests, despite the launch method difference. An example of Lighthouse running against HSL</RWB> shows the results in the report below.
