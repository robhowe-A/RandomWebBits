GUIDE: Dev Tools --> Memory Tab

Open the dev tools tab with CTRL + SHIFT + J and navigate to the memory tab. In firefox, be sure to use CTRL + SHIFT + I

Take a snapshot of a favorite web page. A snapshot is like an instant copy, and a heap snapshot of memory from a web browser will include all DOM elements.

Info: Firefox's memory tab has a call stack option. Depicted below is a nested function from main that expands the view of list items when clicked.
