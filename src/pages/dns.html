LEARN: DNS

Domain Name System, DNS, empowers computers to find things on the internet. That is a big concept. A dns server will tell a client what IP address matches the domain request.

Dns operates on port 53 via UDP for client queries or TCP for zone transfers.

Domain registrars use records (A/AAAA/CNAME/MX/others) to tell nameservers that a domain exists. Without a record of existence, a domain/website can only be reached from the network it is hosted within. Dns works in a hierarchical fashion utilizing cached entries to find sites from the internet's dns root servers.1

Domain Name System
DNS is a resolution method associating a domain name to an IP address.
DNS Records
DNS records are Resource Records (RRs) that map the domain to things like IPv4, IPv6 or an alias (CNAME).
Nameservers
A domain's DNS server which communicates with resolvers from a domain.
Registrars
Domain registrars are places where domains can be bought and managed, like GoDaddy, NameCheap, or Google Domains.
Resolvers
Internet operating nameservers in contact with root servers.
Root Servers
13 root servers serve DNS content globally.
